云栖咖啡品牌官网

一家精品咖啡品牌的线上门面，从视觉到代码一站式交付。

Web 开发 Astro Tailwind 2025
☕

项目背景

云栖咖啡是一家主打「在地烘焙」的精品咖啡品牌，旧官网信息陈旧、移动端体验差， 无法承接门店扩张带来的线上需求。客户希望新官网既能讲好品牌故事，又足够轻快，方便日后自行更新内容。

我的职责

  • 参与品牌视觉梳理，确定「大地色系 + 手写感字体」的整体风格方向；
  • 独立完成全站 8 个页面的设计与响应式开发；
  • 搭建内容可配置的数据结构，门店信息、菜单上新无需改代码；
  • 做性能与 SEO 专项优化，Lighthouse 性能评分从 78 提升到 98。

技术方案

  • 框架：Astro（静态输出，零运行时 JS 也能开箱即用）；
  • 样式：Tailwind CSS + 自定义设计令牌（颜色/间距/字体）；
  • 图片：AVIF 格式 + 响应式尺寸 + 懒加载；
  • 部署：Vercel，接入 GitHub 仓库后自动构建发布。

成果与亮点

  • 上线后移动端访问占比 68%，无任何布局问题反馈；
  • 首页 LCP 1.4s，SEO 基础评分满分，上线两周即被搜索引擎收录；
  • 品牌方通过简单的数据文件即可更新菜单与门店信息，无需依赖开发。
