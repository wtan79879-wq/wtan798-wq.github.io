CSS 现代布局完全指南：Grid 与 Flexbox 实战

🖋️ 林一凡 2026-02-08 12 分钟阅读 CSS 布局
🧱

很多同学把 Grid 和 Flexbox 当成「二选一」的对手，其实它们是互补的两套工具。 记住一句口诀：一维布局用 Flexbox，二维布局用 Grid。下面用实战场景讲清楚怎么选、怎么写。

一、什么时候用 Flexbox

当元素沿一个方向排列时，Flexbox 是最简单直接的选择：

  • 导航栏的水平菜单；
  • 按钮组、标签栏的对齐；
  • 卡片内容（标题、描述、操作按钮）的垂直排布；
  • 「最后一项贴底」的经典问题：margin-top: auto。

二、什么时候用 Grid

当需要同时控制行和列，或希望元素能「跨越」网格时，用 Grid：

  • 整页布局（header / main / sidebar / footer）；
  • 作品集、博客列表等卡片网格；
  • 需要自动填充的响应式网格。

一个最常用的响应式网格写法，三行搞定：

.grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(280px, 1fr));
  gap: 24px;
}

这段代码的含义：每列最小 280px，放不下就自动换行，列数自适应。 无论屏幕多宽，它都能自动铺满，不需要写任何媒体查询。

三、实战：导航栏 + 内容区

导航栏水平排列且右侧按钮贴边，用 Flexbox：

.header {
  display: flex;
  align-items: center;
  justify-content: space-between;
  gap: 16px;
}
.header nav { display: flex; gap: 8px; }

内容区需要「左侧正文 + 右侧侧边栏」，且正文内还有卡片网格，内外搭配：

.layout {
  display: grid;
  grid-template-columns: 1fr 300px; /* 自适应 + 固定侧栏 */
  gap: 32px;
}

四、避坑清单

1. 给 flex/grid 子项设置了 width/height 但没生效？检查是否设置了 flex-shrink: 0。
2. 网格项被拉伸得很难看？检查 align-items 与 place-items。
3. 间隙没有生效？gap 只在 flex/grid 容器上有效，子项上写 margin 是旧做法。

五、移动端适配建议

  1. 优先用 auto-fill + minmax 实现「少写媒体查询」的响应式；
  2. 确实需要断点时，从 768px 和 1024px 两个档位起步；
  3. 导航在移动端收成汉堡菜单（本网站就是纯 CSS 实现的）。
